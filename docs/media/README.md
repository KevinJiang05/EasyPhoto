# 展示素材来源

本目录用于存放 EasyPhoto 实际运行界面的截图和演示预览。四张截图取自 Android 10 模拟器，分辨率均为 720 × 1600，未将设计稿重绘为应用画面。

相机取景与实际拍摄结果是 Android 模拟相机的标准测试图；相册另准备了本项目原创的房屋、树木和风景绘图。绘图只是相册演示数据，不代表由相机拍摄得到。素材不包含真实家庭照片、人物、设备序列号或位置元数据。

| 文件 | 内容 |
| --- | --- |
| `home.png` | 日常首页 |
| `camera.png` | 后置拍摄页 |
| `gallery.png` | 两列照片相册 |
| `viewer.png` | 全屏照片浏览 |
| `demo.gif` | 简短操作预览 |

完整演示 MP4 随 GitHub Release 提供，时长 40 秒、1280 × 720、无声。视频由实际操作录屏和步骤说明组成，结尾保留首页画面；GIF 为缩小后的预览。合成使用 HyperFrames 0.8.188（准备阶段为 0.8.186，导出前升级并重新检查）。

模拟器演示用于说明交互，不代表真机相机画质、性能或新增流程已完成真机验收。历史真机结果见 [验收记录](../acceptance-record.md)。

## 2026-06-27 CameraX 解绑问题修复

- 问题现象：用户反馈前后置拍摄页仍会卡死，并出现“拍照失败”。
- 日志定位：EasyPhoto 本机日志出现 `Not bound to a valid Camera` 与 `Camera is closed`。
- 根因：首页预览组件即使未开启实时预览，离开首页时仍执行 `ProcessCameraProvider.unbindAll()`，可能在拍摄页完成绑定后把拍摄页的 `ImageCapture` 一并解绑。
- 修复方式：当首页实时预览关闭时，首页不再注册 CameraX 绑定/解绑逻辑；当首页实时预览开启时，只解绑首页自己绑定的 Preview 用例，不再全局 `unbindAll()`。
- 后置实拍验证：通过，安装新版后点击后置拍摄并实际拍照，进入拍照成功页；日志新增后置拍照保存成功及对应的 MediaStore 地址。
- 构建验证：通过，`assembleDebug`、`testDebugUnitTest`、`lintDebug`、`git diff --check` 均通过。

## 已知限制

- EasyPhoto 不等同于荣耀或华为原厂相机。
- 夜景、HDR、AI 场景、多帧降噪等厂商私有计算摄影能力不保证复制。
- 当前不是 Kiosk 锁机。
- 当前不提供删除与存储管理。
- 存储空间满时需要联系家人处理。
